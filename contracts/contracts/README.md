# /contracts/contracts

Solidity source lives here.

Phase 0 intentionally leaves this directory empty of real contracts —
the goal of this phase is only to confirm the toolchain (Hardhat,
OpenZeppelin, network configs) compiles and connects cleanly.

- Phase 1 adds `FeeRouter.sol` (BSC / PancakeSwap wrapper).
- Phase 2 adds `EthFeeRouter.sol` (Ethereum / Uniswap wrapper).
